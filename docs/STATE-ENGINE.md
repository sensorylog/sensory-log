# Phase C — State Engine\n\nSensory Log keeps observations and derived state separate.\n\n## Flow\n\n```\nraw check-in entries\n        ↓\nnormalization\n        ↓\nstate engine\n        ↓\ncurrent capacity + loads + baseline\n        ↓\nneeds\n        ↓\ncalm UI / regulation\n```\n\n## Rules\n\n- Raw entries remain the source of truth.\n- The state engine is pure: it does not write storage, call Firebase, call AI, or mutate entries.\n- Derived values can always be recomputed from the saved history.\n- Missing observations stay missing; the engine does not invent signals.\n- Cognitive load is currently null because the current check-in schema has no direct cognitive-load observation.\n- Capacity is a 0–5 derived value based only on available current signals.\n- Baselines use prior logged days and never replace the current observation.\n- Need detection is descriptive and action-oriented; it is not a diagnosis.\n- Confidence reflects how much current and historical information is actually available.\n\n## Current derived dimensions\n\n- capacity\n- loads.sensory\n- loads.social\n- loads.cognitive\n- loads.masking\n- loads.recoveryNeed\n- baseline.energy\n- baseline.sensory\n- baseline.socialBattery\n- capacityDelta\n- confidence\n- needs\n\nLater phases can add direct cognitive-load observations, richer context, recovery curves, and the personal model without changing the ownership boundary.\n
