# Phase G — Personal Operating Manual

The operating manual is a local-first personal model, not a static notes page.

## Rules

- Explicit preferences are user-declared.
- Strengths are user-declared.
- Accommodation requests are user-authored.
- Communication preferences and scripts are user-declared.
- Historical observations remain evidence and are displayed separately.
- Repeated log values are never silently promoted to identity, diagnosis, strength, or preference.

## Flow

\`saved manual + raw entries -> personal model -> calm UI\`

Historical evidence reports recurring logged items such as helpful inputs, drains, and body signals. It does not rewrite the declared model.

## Accommodation builder

Each accommodation contains a plain-language need and the user's own request. Sensory Log does not decide whether a request is medically or legally required.

## Storage

The model is stored through the canonical local storage adapter and remains available offline. Firebase, AI, and network access are not required.
